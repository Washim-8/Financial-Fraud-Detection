## 📌 Overview

This project is a real-time fraud detection engine designed to identify suspicious financial activity before transactions are authorized. Built to simulate the architecture of modern banking and fintech security systems, it analyzes behavioral patterns such as transaction volume, geographic distance, time of purchase, and authentication methods.

Instead of relying on fragile, static rules, the core engine leverages an advanced machine learning model to instantly evaluate context and compute a dynamic risk probability, effectively separating legitimate consumer behavior from malicious exploitation.

---

## ✨ Features

- **⚡ Instant Threat Analysis:** Real-time transaction validation returning targeted risk probability scores.
- **🤖 Advanced ML Pipeline:** Powered by an XGBoost algorithm structured to handle complex, non-linear fraud patterns.
- **⚖️ Imbalanced Data Handling:** Synthetic fraud footprints are gracefully balanced during model training using SMOTE techniques.
- **🧠 AI Explainability:** Transparent insights immediately reveal *why* a specific transaction was flagged (e.g., "Abnormal purchase ratio" or "High distance from home").
- **🌐 Premium Dashboard UI:** Clean, modern, and responsive Flask-based web interface for live monitoring and manual scenario testing.

## 📂 Project Structure

- `train_model.py` — Engine script for generating synthetic transactional data, embedding fraud patterns, and training the XGBoost classifier.
- `app.py` — The core Flask backend that exposes the prediction endpoints and serves the application.
- `models/` — Binary directory containing the serialized, production-ready ML model and data scalers.
- `templates/` — Contains the structured HTML views (`index.html`, `about_contact.html`).
- `static/` — Holds the styled UI components (`css/style.css`) and client-side logic (`js/script.js`).

---

## ⚙️ How It Works

1. **Data Synthesis:** Synthetic transactional datasets are generated, mimicking real-world spending habits and structural anomalies.
2. **Model Training:** Data is balanced via SMOTE, and an XGBoost model learns to identify nuanced fraud indicators from high-dimensional behavior vectors.
3. **Inference Pipeline:** The trained model and data scalers are loaded into memory on the Flask backend upon initialization.
4. **Live Prediction:** User inputs or simulated webhooks hit the endpoint; the feature array is scaled and passed to the model.
5. **Decision & Explanation:** The system returns a classification (Legit/Fraud), a confidence probability, and human-readable AI explainability factors to the frontend UI.

## ▶️ Installation & Setup

```bash
# 1. Clone the repository
git clone https://github.com/Washim-8/Financial-Fraud-Detection.git
cd Financial-Fraud-Detection

# 2. Setup a virtual environment
python -m venv venv
venv\Scripts\activate  # On macOS/Linux use: source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Train the ML Model (generates resources in the /models directory)
python train_model.py

# 5. Launch the Dashboard
python app.py
```
